# Research and evidence

This folder holds the evidence behind the numbers on the model pages, together with the licence
and stack research that the configurations, the guards and the shipped code cite by path. Each
file keeps the record it was written to keep: the protocol declared before a run, the numbers
that run produced, the licence text read from a primary source, or the count computed from
artefacts already on disk. The folder is flat and has no subdirectories; the group column below
is a subject label, not a directory.

How to read these documents. Every accuracy value travels with the checkpoint sha256 that
produced it, and a value without its hash is not quotable, because one value can belong to two
different checkpoints. The machine-readable dumps in this folder are the exception in form only:
they key their rows by run name, and the checkpoint sha256 behind each run is recorded in
`eyes-instrument-grading.md`. The fall numbers are measured on public, licence reviewed, acted
fall footage. The seizure numbers are measured on real clinical footage from the WU-SAHZU
corpus, used as an interim prototype train and test surface under the registry grant recorded
in `configs/datasets/wu_sahzu_emu_trainsplit.yaml`, whose `TRAIN_PROTOTYPE` bucket is governed
by POLICY.md, rule 6. None of them is clinical detection performance, and none of them is a
ward false-alarm rate. Re-identification figures taken from published benchmarks are external
results, and they are upper bounds until they are re-measured on this stack. A document that
records a rejected arm is kept for the same reason as one that records a promotion: the
measurement is the record.
